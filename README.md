## 🚀 البدء

### الطريقة 1: تشغيل محلي

1. انسخ المستودع:
```bash
git clone https://github.com/aloui19940724-alt/hhhhg.git
cd hhhhg
```

2. افتح `index.html` في متصفحك أو استخدم Live Server

### الطريقة 2: نشر على الإنترنت

#### أ) GitHub Pages
1. اذهب إلى Settings → Pages
2. اختر Branch: main
3. الموقع سيكون: `https://aloui19940724-alt.github.io/hhhhg/`

#### ب) Vercel
```bash
npm install -g vercel
vercel
```

#### ج) Netlify
اسحب وأسقط المجلد على [netlify.com](https://netlify.com)

## 🔧 التخصيص

### تغيير الألوان

عدّل ملف `style.css` في جزء `:root`:

```css
:root {
    --primary: #6366f1;      /* اللون الأساسي */
    --secondary: #8b5cf6;    /* اللون الثانوي */
    --accent: #ec4899;       /* لون التأكيد */
    --dark: #1f2937;         /* اللون الداكن */
    --light: #f9fafb;        /* اللون الفاتح */
    --gray: #6b7280;         /* اللون الرمادي */
}
```

### تغيير رقم واتساب

عدّل `script.js`:

```javascript
const whatsappNumber = 'رقمك_بدون_رموز'; // مثال: 966501234567
```
